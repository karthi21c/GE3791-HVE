# GE3791 Human Values and Ethics: course website

Static course site for B.E. Mechanical Engineering, Semester VII (2026–2027), Krishnasamy College of Engineering and Technology, Cuddalore.

- `index.html`: the whole site (overview, learning resources, weekly schedule, assessment plan, contact)
- `style.css`: styles
- `assets/kcet-logo.png`: college header image
- `.nojekyll`: tells GitHub Pages to serve the files as they are

No build step. To publish: repository Settings > Pages > Deploy from a branch > `main` / root.
