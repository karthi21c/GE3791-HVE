How to write a long answer: one-line meaning, then 4 to 5 points each with an example, then one line of conclusion. If an idea is hard, think of it first in Tamil, then write it in English.

How the paper is set

Part C tip: answer each 5-mark part with four or five points, and use the facts of the case in every point. When asked about constitutional protection, name the Article (for example 14, 15, 16, 21) and, for the workplace, the POSH Act, 2013.
